# Banana Deals

First build of Banana Deals — a UK tech and gaming deals website.

## Current version

- Bright Banana yellow / black / white visual identity
- Responsive homepage
- Search
- Category filtering
- Deal cards
- Simple `deals.json` data source
- Affiliate URL field ready to be replaced with real links

## Next stage

The next build should replace the simple JSON file with a proper deal workflow/database:

Source/feed → Deal Inbox → Review → Approve → Publish → Expire/update.

Do not build the complicated automation yet. First prove the front end and manual deal workflow.
